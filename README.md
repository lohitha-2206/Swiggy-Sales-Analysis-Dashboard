# 🍽️ Swiggy Sales Analysis Dashboard (Excel)

## 📌 Project Overview
This project is an interactive Swiggy Sales Analysis Dashboard built using Microsoft Excel. The dashboard provides valuable insights into sales performance, customer ratings, order trends, food category contributions, and geographical sales distribution across different states and cities.

The objective of this project is to transform raw sales data into meaningful business insights through data cleaning, Pivot Tables, Pivot Charts, KPIs, Slicers, and Dashboard Design.

## 📊 Insights Generated

- Non-Veg food contributes approximately 36% of total sales.
- Veg food contributes approximately 64% of total sales.
- Bengaluru is the highest revenue-generating city.
- Monthly sales remain relatively stable with slight fluctuations.
- Weekend sales are higher compared to weekdays.
- Certain states contribute significantly more revenue than others.
